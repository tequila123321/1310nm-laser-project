# Project Tasks

## Phase 0 - Decisions to Freeze

- [ ] Confirm device type: FP, DFB, DBR, VCSEL, or PIC laser.
- [ ] Confirm target output power.
- [ ] Confirm CW only or direct modulation.
- [ ] Confirm operating temperature range.
- [ ] Confirm material route: InGaAsP/InP or AlGaInAs/InP.
- [ ] Confirm fabrication route: internal process, university lab, or InP foundry.
- [ ] Confirm available software licenses.

## Phase 1 - First Design Models

- [ ] Calculate photon energy for 1310 nm target.
- [ ] Select MQW starting structure from literature or foundry PDK.
- [ ] Build 1D active-region model.
- [ ] Build slab/ridge waveguide mode model.
- [ ] Sweep ridge width from 1.5 um to 3.0 um.
- [ ] Estimate optical confinement factor and internal loss.
- [ ] Estimate threshold gain.
- [ ] Calculate first-order DFB grating period.
- [ ] Sweep grating coupling coefficient and cavity length.

## Phase 2 - Electro-Thermal Model

- [ ] Estimate series resistance and current spreading.
- [ ] Build chip-level thermal model.
- [ ] Sweep ridge width and cavity length for junction temperature.
- [ ] Estimate thermal rollover risk at target current.
- [ ] Define submount and mounting assumptions.

## Phase 3 - Mask Test Matrix

- [ ] Add FP reference lasers.
- [ ] Add DFB lasers with period sweep around 1310 nm.
- [ ] Add ridge width sweep.
- [ ] Add cavity length sweep.
- [ ] Add grating depth or duty-cycle sweep.
- [ ] Add TLM structures.
- [ ] Add sheet resistance and Van der Pauw structures.
- [ ] Add alignment marks and cleave marks.

## Phase 4 - Measurement Plan

- [ ] L-I-V at 25 C.
- [ ] Spectrum versus current.
- [ ] Spectrum versus temperature.
- [ ] SMSR versus current and temperature.
- [ ] Far-field pattern.
- [ ] Polarization.
- [ ] Series resistance.
- [ ] Thermal rollover.
- [ ] Small-signal modulation if direct modulation is required.
