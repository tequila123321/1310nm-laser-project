# Simulations

Put simulation scripts and model input files here.

Suggested first files:

- `active_region/` for MQW gain and band-structure models.
- `waveguide/` for ridge/slab optical mode simulations.
- `dfb/` for CMT/TMM grating and cavity sweeps.
- `thermal/` for chip and submount thermal models.

Do not commit large binary simulation result files. Export compact summaries or plots instead.
